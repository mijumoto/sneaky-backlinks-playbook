# Weekly Checklist

## Every week
- [ ] Check latest posts from @ConnorShowler and similar accounts
- [ ] Mine 2–3 SEO agency or competitor backlink profiles
- [ ] Run 3–5 search operator queries for new directories / Web 2.0
- [ ] Review specialized bots’ proposals
- [ ] Deduplicate and insert unique high-DR candidates
- [ ] Fill DR on at least 10 existing null entries
- [ ] Note any new platforms or technique changes
- [ ] Update this playbook if needed

## Quality bar
- Target DR 70+
- Prefer platforms with real traffic
- Document source and verification status
- Keep categories consistent

## Output
- New documents in `sneaky_backlinks.opportunities`
- Short summary of what was added and why
- Any process improvements for next week
